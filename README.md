# 言橋 · 英日語學習

手機優先的英日語學習 App：每日 **20 分鐘**，依程度練習**說、聽、讀、寫**，並追蹤學習目標與進度。

## 功能

- 引導設定：語言（英語／日語）、程度（初／中／高）
- 今日橋段：20 分鐘進度環、連續學習天數
- 四技能練習：跟讀、聽力選擇、閱讀理解、書寫／填空
- 學習目標：自訂天數與聚焦技能，進度條追蹤
- 進度頁：技能分鐘數、近七日紀錄、語言／程度設定
- 資料保存在瀏覽器 `localStorage`

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
npm run preview
```
